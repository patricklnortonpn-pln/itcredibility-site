# IT Credibility landing page

A responsive, single-page website for [itcredibility.com](https://itcredibility.com), designed for deployment through Cloudflare Pages.

## Cloudflare Pages settings

- Production branch: `main`
- Framework preset: None
- Build command: `exit 0`
- Build output directory: `.`

## Before launch

Confirm that `hello@itcredibility.com` is the preferred contact address. If not, replace it in `index.html`.
